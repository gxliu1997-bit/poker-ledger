# 牌局账本

适合手机使用的德州扑克牌局买入与结算记录工具。网页为纯静态文件，无需后端；首次联网打开并完成离线缓存后可离线使用。

## 功能

- 默认每手 ¥300 的整手买入，可快速补买 1、2、3 手；也可切换任意金额模式。
- 牌局中途添加玩家、记录补买、离场兑出和再次入场。
- 查看全桌累计买入、已兑出、玩家暂时输赢。
- 一次性结算整场牌局，按玩家显示最终输赢及全桌差额。
- 查看历史牌局和逐笔记录，导出、导入 JSON 备份。

每台设备的记录只保存在该设备浏览器中，不会自动同步。清理浏览器数据或更换域名可能导致原记录不可见，请定期导出备份。

## GitHub Pages 发布

打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，再选择 **main** 和 **/(root)**，点击 **Save**。发布完成后以该页面显示的网址为准。

国内网络的访问情况需用关闭 VPN 的手机流量和 Wi-Fi 实测。GitHub Pages 的默认网址不保证在每个国内网络稳定可达。
